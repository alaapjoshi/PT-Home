How the angle and reps are computed

Three steps, run on every sample in the browser.
1

Fuse each sensor

The gyroscope is smooth but drifts. The accelerometer is noisy but stable. A complementary filter blends them.

pitch = 0.98 × (pitch + gyro·dt)
      + 0.02 × accelPitch
2

Compare the two

The joint angle is the difference between the two pitches, minus the straight-arm baseline set at calibration.

Δ = pitchB − pitchA
angle = |Δ − baseline|, 0°–145°
3

Count reps

Hysteresis stops jitter from double counting. A rep counts above 65°, and the counter re-arms below 25°.
